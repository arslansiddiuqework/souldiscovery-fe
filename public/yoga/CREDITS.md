# Yoga illustration credits

Professional human-figure yoga pose illustrations are sourced from the
open [Yoga API](https://github.com/alexcumplido/yoga-api)
(`https://yoga-api-nzy4.onrender.com`), hosted on Cloudinary.

Assets are bundled locally under `/public/yoga/*.svg` so the feature does
not depend on the remote API at runtime.

Motion playback uses the MIT-licensed [`lottie-react`](https://www.npmjs.com/package/lottie-react)
library for soft ambient breath rings. Pose figures themselves are the
Yoga API SVGs with gentle CSS motion (and Cat↔Cow crossfade).
